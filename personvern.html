Loff metrics · sist oppdatert 12. september 2026

Loff metrics er et internt analyseverktøy som brukes av Lucky View for å følge statistikken til Loff sine egne kontoer i sosiale medier. Denne erklæringen beskriver hvilke data verktøyet behandler.

Verktøyet behandler ingen personopplysninger om publikum eller følgere. Det henter kun tall som allerede er tilgjengelige for kontoeieren selv, i sammenstilt form.

Hvilke data behandles

  • Statistikk på kontonivå: antall følgere, rekkevidde, visninger, likes, kommentarer, delinger og lagringer per dag.
  • Data om egne publiseringer: tittel eller bildetekst, lenke, publiseringstidspunkt og tallene for det enkelte innlegget.
  • Tilgangsnøkler: tokens som gir lesetilgang til kontoene. De lagres kryptert.

Verktøyet henter ikke meldinger, kommentarteksten til andre, kontaktlister eller opplysninger om enkeltpersoner, og det kan ikke publisere, endre eller slette innhold.

Bruk av data fra Google og YouTube

Verktøyet bruker YouTube Data API, YouTube Analytics API og YouTube Reporting API med lesetilgang (youtube.readonly og yt-analytics.readonly), autorisert av kontoen som administrerer YouTube-kanalen.

  • Dataene brukes kun til å vise statistikk for kanalen i et privat dashboard og i en intern ukesrapport.
  • Dataene deles ikke med tredjeparter, selges ikke, og brukes ikke til annonsering eller profilering.
  • Bruken følger Google API Services User Data Policy, inkludert kravene om begrenset bruk.
  • Tilgangen kan trekkes tilbake når som helst på myaccount.google.com/permissions. Da stopper innhentingen umiddelbart.

Tilsvarende gjelder for Instagram, TikTok og Snapchat: verktøyet bruker plattformenes offisielle API-er med lesetilgang, autorisert av kontoeieren, og tilgangen kan trekkes tilbake i innstillingene på hver plattform.

Lagring og sikkerhet

  • Tallene lagres i en database i et privat kodelager hos GitHub, som bare Lucky View har tilgang til.
  • Tilgangsnøkler lagres kryptert, eller som krypterte hemmeligheter hos GitHub. De vises ikke i logger.
  • Dataene lagres så lenge verktøyet er i bruk, og slettes på forespørsel.

Bruk av AI

Den ukentlige rapporten lages ved å sende de sammenstilte tallene til Anthropics Claude API, som returnerer en tekstlig analyse. Det sendes ingen personopplysninger, og dataene brukes ikke til å trene modeller.

In English

Loff metrics is an internal analytics tool used by Lucky View to track the performance of its own social media accounts. It reads aggregated statistics (followers, reach, views, likes, comments, shares, saves) and metadata about its own posts, using the platforms' official read-only APIs as authorized by the account owner. Data from Google APIs is used solely to display statistics in a private dashboard and an internal weekly report; it is never shared with third parties, sold, or used for advertising, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. No personal data about audiences or followers is processed. Contact: kontakt@luckyview.no.
